Use the {{ name }} from the input image exactly as it is: keep its shape, cap, glass, liquid colour, proportions and finish unchanged, and keep it completely wordless (no label, letters or logo).

{% if framing == "macro" %}

{% elif framing == "event" %}
Keep it the clear subject of the frame while the physical event below happens around it; nothing hides it.
{% else %}
